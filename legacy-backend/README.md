# AuthentiScan Backend

Backend API for the AuthentiScan capstone project.

## First-time setup

1. Install Node.js 18 or later.
2. Copy `.env.example` to a new file named `.env`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:5000/api/v1/health` in a browser.

## Useful commands

```powershell
npm run dev
npm test
```

## Current milestone

The foundation has one health endpoint. The next milestone adds the MySQL database and user authentication.
